Most tokenized-stock tools stop at the buy button. Steward starts where they stop.

We built Steward for the BNB Hack: Tokenized Stocks Edition to answer one plain question. Once you own a tokenized stock on BNB Smart Chain, what do you actually hold? And what does it take to look after it? The whole field is buy-side. Steward is own-side.

What it does

Steward has four parts over one typed core.

Know shows the truth about a holding. It resolves every bStocks token by its beacon, never by its symbol, because the bStocks symbol is heavily squatted by scam clones on BSC. A genuine bStocks token is a beacon proxy that points at the shared beacon 0x156d6DCe9A4F6139a3406F1f021F1A4880dE93A3. Anything else is rejected before it costs you. Know then reconstructs your true cost basis and position from Transfer history, both realized and unrealized. It surfaces dividend income and catches the silent rebase that moves a balance on a dividend or a split.

Grow turns a conviction into a rule. A thematic basket like AI chips is a rule over genuine bStocks, with drift detection and a rebalance plan. Execution stays a separate guarded step.

Use lets you live off a position without selling it. A pre-trade guard folds authenticity, premium-to-NAV, pool depth, slippage and US market hours into one verdict: allow, warn, resize or block. Swipe borrows USDT against a bStocks position on Venus, spot collateral, not a perp. This part is real, not a mock. Genuine bStocks are listed Venus collateral. We verified TSLAB, NVDAB, SPCXB and SKHYB as live markets on chain.

Compare puts the same underlying side by side across bStocks, Ondo and xStocks. It is read-only and states plainly what we measured: bStocks has deep PancakeSwap liquidity, Ondo is thin and xStocks is dust, so a cross-provider DEX arbitrage is not executable on today's BSC liquidity. We would rather say that than promise a trade that will not fill.

The suite

Under the four parts sits one real suite. @steward/sdk is the typed core, with eight modules: chain, market, ledger, lending, guard, basket, providers and api. An MCP server exposes eight read-only tools to any MCP client like Cursor or Claude Code. A Next 16 dashboard is the front door for someone who is not crypto-native, four tabs over seven API routes that read BSC live. A Wallet Skill routes natural-language intents to the SDK and returns a verdict plus safe parameters. It ships MIT so the Binance skills hub can adopt it. An Agent Studio agent carries an ERC-8004 identity against the Identity Registry 0x8004A169FB4a3325136EB29fA0ceB6D2e539a432 and builds unsigned transactions only. 37 unit tests cover the pure logic, all green.

Both stack specials are load-bearing, not decoration. The Wallet Skill earns Best Use of Agentic Wallet / Wallet Skills. The Agent Studio agent earns Best Use of BNB Agent Studio.

What is live, what is honest

Steward is built to be honest about what a judge can run today. Every on-chain read is live and free: authenticity by beacon, the position ledger from Transfer history, PancakeSwap v3 price, depth and slippage, the Venus reads behind Swipe and the cross-provider comparison. No key, no gas. The dashboard runs on these today at https://bnb-tokenized-stocks.vercel.app , where NVDAB reads about $225 on a roughly $1.5M PancakeSwap pool.

We are just as plain about the edges. The Binance Web3 API, the source of the reference price and the corporate-action feed, sits behind a clean interface with a keyless mock adapter, so premium-to-NAV is approximate until the API key session wires the live client. Live trades and on-chain deploys need BNB for gas, so the SDK and the agent build unsigned transactions and stop at the signing line. ERC-8183 is a draft with no deployed contract on BSC, so the agent's job model follows the draft shape and says so. Payout and any deploy route through the house wallet 0xDB6c6340342e71A63cD11Ebac2185204b7777777.

Spot only. No perps, no margin loops.
